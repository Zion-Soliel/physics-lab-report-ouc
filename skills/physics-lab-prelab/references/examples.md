# 用户认可的预习报告示例

这些文件是用户认可稿的原样副本，用于学习组织方式与表达密度，不作为新实验的科学依据，也不是固定模板。

后续修正规则：预习报告还应内嵌指定项目相关的讲义电路图、装置图和函数曲线。下面保留的历史文字稿尚未包含配图，不能据此省略新报告中的图；配图要求以 SKILL.md 为准。

后续还新增了“实验仪器”部分：优先摘取讲义，未单列时从实验内容归纳，必要通用器材可合理补充。历史样例未含这一部分，新报告应按 SKILL.md 补齐。

- [RLC 电路综合实验](accepted-rlc.md)：优先作为风格参考。展示多项目范围筛选、稳态与暂态的分节、必要分类、短要点与公式相邻、相位差约定和来源页码。
- [磁学综合实验](accepted-magnetism.md)：涉及磁场分布、标定或带符号组合测量时可参考。展示由机制连接测量公式、读数极性解释、一般式与特殊条件的区分。

采用其中“重点短句＋关键公式＋符号说明”的表达方式；不照搬背景、页码和实验参数。样例中的具体近似、条件或科学表述仍应在新任务中回到当前教材核验。样例的公式长度不是增加公式的理由，符号说明也不能代替正文分析。

两份样例遵循原理叙述正文 400 字以内的约定，标题、公式、符号说明和来源不计入；不是整份 Markdown 文件只有 400 字。实验后报告的讨论长度与本规则无关。
