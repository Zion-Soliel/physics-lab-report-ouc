# 大学物理实验报告

## 依据与范围

- 以当前用户要求、教师指定项目及其教材为依据；先读材料，不能按实验名称凭记忆写通用报告。旧预习报告用于衔接，公式仍回教材核对。
- 阅读指定项目时追踪其引用的前置步骤、数据表和计算公式，尤其“把结果填入表6”“与第7项合并作图”等跨项目依赖。建立所需数据、表格和曲线清单，避免只完成本项截图里直接可见的部分。
- 文字 PDF 提取后，对关键公式、图表、表头极性顺序核对原页面。教材疑似错误须单独核验，不能盲抄或默默改成另一种方法。
- 常规排版与有依据的估算可直接决定；只追问影响结果且不能合理推定的实验事实。数据不足时先做可完成部分，明确缺项，不能用理论值冒充实测值。

## 输出约定：正文与图表分别交付

以项目历史抄写稿提炼的写作规范为默认参考：首次生成或调整风格时读取 [写作规范](references/writing.md)；需要示例时再读 [历史文字示例](references/accepted-handwritten.md)。示例只规定详略与组织方式，不能复用其中的实验参数或数值。

默认交付：

1. **手写正文.md**：不嵌入图片，不放完整数据表，保留准确的图表编号引用；按实验项目写必要计算，随后集中写不确定度、结果和讨论。正文采用可直接写入正式实验报告的表述。
2. **图表附件.md**：独立文件，集中完整数据表、处理结果表及 Python 生成的 PNG，图表有标题、物理量、单位、实验条件和清晰图例。用户明确指定可直接打印的 PDF/Word 时再用相应工具生成并检查页面；不能将 Markdown 宣称为已排版的打印 PDF。
3. 保留可复现的计算绘图脚本及原始数据溯源记录。若用户要详解版，另提供来源、假设、校核和复现说明；不把这些工作说明塞入手写正文。

正文和附件共用同一份计算结果与编号映射。按附件的最终顺序分配图号、表号；教材原表号另记为来源，不能混用。“如图”“见上表”改成明确编号。正文删去图表不等于整个交付省略图表。

## 计算与课程规则

计算前读取 [课程数据处理规则](references/course-rules.md) 的相应部分。其适用范围是当前用户提供讲义的课程，后续课程明确规定优先。核查教材错误时读取 [讲义校核记录](references/errata.md)。

- 原始数据不覆盖、不静默删点；复算已有计算列，记录单位、读数顺序、坐标修正及标定来源。已确认的坐标修正不重复执行。
- 共用计算先定义一次；各项目写方法、关键公式、带单位代入、结果，重复逐点换算引用同一公式并见附件表。不能将“精简”变成省略关键计算关系。
- 仅在本项目课程规则的适用条件下默认取 t=1，不确定度一位有效数字，结果末位对齐；中间保留保护位。优先报告合成标准不确定度，扩展不确定度注明覆盖因子和条件。
- A/B 按评定方法分类；不同极性、位置或电流下的读数不混作重复测量。缺少重复轮次不等于 A 类分量为零。
- 不确定度估计须保留来源与适用条件，即使在手写版也用一句话说明简化范围。只计部分贡献时标为简化估计，不把缺失贡献当零，不把记录末位当作已知厂家准确度。
- 由斜率得到结果时必要地计算拟合参数标准误差；检查模型假设及残差，不只看 R²。不重复合成已包含的噪声；共享标定导致相关性时考虑协方差。
- 理论场、理论模型标定得到的灵敏度、独立实测场须准确命名。不得将“实测斜率÷理论场”称为纯理论灵敏度。

## 图表与讨论

- 按教材要求逐一完成曲线：单量关系、各分量及其和的同坐标比较、实测与理论对照等，不用一张看似相关的图代替全部要求。
- 用 Python 输出 PNG；检查中文字体、图名、轴标签、单位、图例、刻度、曲线及数据点。误差棒注明表示哪种不确定度。
- 缺少单独测量时，不能从合成测量唯一拆分各分量，不能为画齐曲线编数据。必要时另列明确标识的理论对照图表，实测表保留“未测”，说明仍未完成的实验验证。
- 讨论从本次数据出发：结果趋势、偏差方向和大小、具体误差机制、对应改进。推测不写成事实，不凭理论叠加作循环的实验验证。
- 参照实际抄写稿的讨论风格、语气和内容取舍，不把样稿篇幅理解为压缩要求。默认“实验结果和讨论约1000字”，当次用户或评分要求另有规定时遵从。充分展开结果解释、误差分析、深入思考或延伸及实验设计改进；去掉不适合写入正式报告的聊天、交付说明、软件操作和编辑提示，不因此删减必要的科学分析。

## 交付前核查

逐项核对教师要求和跨项目依赖；确认数值、符号、单位、有效数字、图表引用与附件一致。去掉空标题、重复编号和重复结果段。手写正文不出现文件路径、单元格地址、脚本用法、聊天语气或“待用户确认”等编辑提示；实际科学限制用简短报告语言表达。

修改指定后半部分时保留用户认可的前半部分。不能因为修订技能而改写用户原始样例、原始数据或已提交报告。
